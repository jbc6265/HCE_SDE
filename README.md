# HCE SDE Dashboard

현건회 협력사육성팀 지원현황을 정리한 정적 HTML 대시보드입니다.

## 구성

- `index.html`: GitHub Pages 또는 브라우저에서 바로 열 수 있는 단일 HTML 대시보드
- 원본 기준 파일: `현건회_MES구축_안전사업장구축_전수조사_R3.xlsx`

## 주요 기준값

- 현건회 회원사: 129개사
- 종합등급평가 대상: 125개사
- 종합등급평가 비대상: 4개사
- 3개 파일 통합 대상 풀: 466개 대상
- MES 구축 현황: 완료 54개사, 구축중 49개사, 예정 9개사, 미정 9개사, 미제출 8개사
- 안전사업장 구축 대상: 45개사

## 운영 방법

1. 원본 엑셀 또는 대시보드 HTML을 수정합니다.
2. 최신 대시보드 HTML을 이 저장소의 `index.html`로 반영합니다.
3. 변경 내용을 확인한 뒤 커밋합니다.
4. GitHub에 push하여 이력을 관리합니다.

## 배포

GitHub Pages를 사용하는 경우 저장소의 `main` 브랜치 루트(`/`)를 배포 소스로 지정하면 `index.html`이 대시보드 첫 화면으로 열립니다.

## 주의사항

이 대시보드는 협력사명, 담당 정보, 현황 데이터가 포함된 정적 HTML입니다. 공개 범위가 제한되어야 하는 경우 GitHub 저장소와 Pages 공개 설정을 반드시 확인하세요.
